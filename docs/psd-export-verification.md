# 图层组 PSD 导出验证

2026-09-15，本地实现。

## 行为

图层组卡片、右键菜单和图层编辑器均可导出 PSD。编辑器使用点击时的草稿，
不改变项目已保存状态。每层保持名称、次序、透明度、显隐、位置锁定和独立像素；
移动/缩放烘焙到局部图层位图，保留负坐标与画布外内容。导出不调用生成 API。

`public/layer-psd.js` 负责预检、局部光栅化和合成；Worker 使用固定的
`public/vendor/ag-psd/` 编码，避免同步编码阻塞界面。内存预算、缺失素材、
编码失败和超时均返回错误，并恢复导出按钮。

## 验证结果

- `npm test`：232 项，230 通过、2 项既有平台跳过、0 失败。PSD 专项 12 项。
- 三个新增/修改的前端 JS 文件语法检查及 `git diff --check` 通过。
- 隔离 Edge 浏览器真实载入应用及 Worker：卡片下载、草稿下载、导出中打开编辑器的按钮状态、缺图阻止下载与重试恢复通过。页面错误为 0，生成/写入 API 请求为 0。
- 浏览器导出的 320×400、5 层文件经独立 psd-tools 读取，中文名称、负坐标、缩放边界、50% 与 0% 透明度、隐藏层和位置锁定均正确。
- PSD 缓存合成图与浏览器 PNG 像素误差为 0；强制从 PSD 图层重新合成的最大通道误差为 1/255（透明度量化/舍入）。仅检查缓存预览不足以验证图层顺序。
- 独立读取验证 `ag-psd 31.0.2` 的 children 实际顺序为底→顶；上游 README 此处说明与实现不符。1/2 像素宽透明文档的 RLE 缓冲修复详见 vendor README，15 组窄图尺寸回归通过。

本机验证脚本、浏览器截图、下载的 PSD、预览 PNG 与全量测试日志在
`outputs/psd-export-check/`。临时 Python 验证依赖也仅在此目录，不是应用部署依赖。
尚未在 Photoshop 桌面端手动打开；当前独立结构/像素验证不等于覆盖其所有版本。

## 部署

随源码包含 `layer-psd.js`、`layer-psd-worker.js` 和完整 `vendor/ag-psd/`。
无需 npm 安装或构建，刷新原画布地址即可加载。格式为 RGB / 8 位像素图层，
不包含文字识别、矢量重建或智能对象。

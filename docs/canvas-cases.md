# 画布创作案例

在画布顶部点击「创作案例」，或在「添加节点」中进入。可以勾选当前画布的素材，也可以批量导入本地图片、视频和音频。六种流程均为追加操作，可以一次撤销、重做；导入并处理的图片会同时保留原图节点。

| 入口 | 使用方法 | 结果 |
| --- | --- | --- |
| 商品主图方案 | 指定商品原图，勾选可选风格参考，每行填写一个方向 | 每个方向各有可编辑提示词、现有图片生成配置、结果节点；第一张参考始终是商品 |
| 详情页切图 | 选择原图、行列数，拖动分割线，双击删除分割线 | 按原图像素生成独立 PNG，并分组 |
| SKU 图片整理 | 勾选图片，设尺寸、完整保留或居中裁切、留白底色；可每张填写一个规格分组名 | 新尺寸图片及规格分组；底色只填充透明或留白区域 |
| 视频分镜素材板 | 每行一个镜头，填写统一要求；可带主体图片、参考视频及音频 | 每镜头的画面提示词、图片生成、关键画面、运镜提示词、视频生成及输出；音视频另列素材组 |
| 设计参考板 | 每行一个方向，按列表顺序轮流分配参考图 | 方向分组、设计笔记；同组至少两张图片时增加对比节点 |
| 大图素材提取 | 框选图片局部，或切换网格提取 | 独立 PNG 素材；可继续连接到生成节点，或用 SKU 整理调整尺寸及底色 |

点击顶部下载按钮或案例内的「批量导出」，选择媒体后下载 ZIP。图片可保留原格式或转换为 PNG / JPEG。ZIP 包含素材清单、分组信息，可选画布文本；失败项单独列明。工作流 JSON 仍在「工作流模板 → 导出 JSON」中导出。

生成流程使用普通 `imageConfig` / `videoConfig` 和现有 provider、模型、请求及任务查询逻辑。创建流程不会提交生成请求，随后在节点上点击「生成」。提示词按上述案例重新编写，可直接编辑；未接入 DABI 服务，也未新增拆层流程。

音频仅用于本地预览、素材整理和导出，不自动提交给视频生成接口。素材板不包含时间轴剪辑。创建的节点可保存为现有工作流模板。

实现文件：

- `public/canvas-cases.js`：流程图、提示词、像素矩形和分组规则。
- `public/canvas-cases-ui.js`：素材选择、裁切预览、本地处理及 ZIP 导出。
- `public/app.js` 的 `canvasCasesBridge`：复用节点工厂、项目状态、IndexedDB 和单次撤销事务。
- `server/canvas-cases.test.js`：奇数尺寸覆盖、裁切、参考顺序、视频角色、分组、provider 继承及项目切换保护。

为控制浏览器内存，单张输出最多 16,777,216 像素，单边最多 16,384 像素；一次最多生成 100 张切图，单包媒体总量最多 256 MiB。原始媒体仍保存在现有 IndexedDB，项目 JSON 只保存引用。
